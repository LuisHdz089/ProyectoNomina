# 📂 Proyecto Nómina - Administración de Bases de Datos

Este repositorio contiene los scripts y la lógica de base de datos para el sistema de **Gestión de Nómina**, desarrollado como parte de la formación académica en el **Instituto Tecnológico de Veracruz**.

## 🚀 Descripción
El proyecto se centra en la administración, diseño y automatización de una base de datos capaz de gestionar el pago de empleados, deducciones, percepciones y el histórico de nóminas.

## 🛠️ Tecnologías Utilizadas
* **Motor de BD:** SQL Server / MySQL (especifica el que uses)
* **Lenguaje:** Transact-SQL / SQL
* **Herramientas:** Visual Studio Code, Git

## 📂 Estructura del Proyecto
* `/Scripts`: Contiene los archivos `.sql` de creación de tablas, triggers y procedimientos almacenados.
* `/Data`: (Opcional) Scripts de carga de datos de prueba.
